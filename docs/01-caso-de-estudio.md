# Caso de estudio

## Nombre del proyecto

Desarrollo de una plataforma web para la gestión de eventos de seguridad en videovigilancia IP.

## Descripción

La plataforma permitirá gestionar eventos de seguridad generados por sistemas de videovigilancia IP.

El sistema permitirá registrar, clasificar, priorizar, asignar, atender y cerrar eventos, manteniendo la trazabilidad de las operaciones realizadas.

## Problema

Los sistemas de videovigilancia pueden generar diferentes eventos de seguridad que requieren seguimiento y atención. La plataforma busca centralizar la gestión de dichos eventos mediante un sistema web.

## Flujo principal

Evento detectado → Registro → Clasificación → Priorización → Asignación → Atención → Cierre → Auditoría.

## Alcance inicial

* Gestión de usuarios.
* Gestión de organizaciones.
* Gestión de ubicaciones.
* Gestión de dispositivos.
* Gestión de eventos.
* Gestión de asignaciones.
* Seguimiento de eventos.
* Auditoría.
* API REST.

## Evolución prevista

La arquitectura deberá permitir incorporar progresivamente nuevas fuentes de eventos, servicios, mecanismos de integración, notificaciones y capacidades de observabilidad.
