# Desarrollo de una Plataforma Web para la Gestión de Eventos de Seguridad en Videovigilancia IP

## Curso

Arquitectura de Software [IS-488]

## Proyecto

Desarrollo de una plataforma web para la gestión de eventos de seguridad en videovigilancia IP.

## Descripción

La plataforma permitirá gestionar eventos de seguridad generados por sistemas de videovigilancia IP.

El sistema permitirá registrar, clasificar, priorizar, asignar, atender y cerrar eventos, manteniendo la trazabilidad de las operaciones realizadas.

## Objetivo

Desarrollar una plataforma web que permita gestionar de manera centralizada los eventos de seguridad provenientes de sistemas de videovigilancia IP.

## Tecnologías previstas

* Node.js
* TypeScript
* Express
* React
* PostgreSQL
* Prisma
* REST API
* OpenAPI
* Docker
* GitHub Actions

## Arquitectura

La arquitectura inicial será modular y estará organizada para separar las responsabilidades de presentación, aplicación, dominio, infraestructura e integración.

La arquitectura podrá evolucionar progresivamente de acuerdo con los requerimientos y atributos de calidad identificados.

## Flujo principal

Evento detectado → Registro → Clasificación → Priorización → Asignación → Atención → Cierre → Auditoría.
